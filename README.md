# 律动空间演奏台 / Spatial Loop V3.14

最新版源码备份：2026-11-10，Android `3.14 / 44`，Spatial SDK 保持 `6.1.9`。
安装包、校验值及交付说明见 [3.14 Release](https://github.com/hyd1059320441-bot/spatial-dj-v3/releases/tag/v3.14)；
恢复构建与源码清单见 [备份说明](github-backup/README.md)。

节拍俱乐部：手指触碰打击垫，逐轨录制底鼓、拍手、贝斯、旋律与和弦。
演奏台位于有全屋补光的完整虚拟夜店内，配有舞池、光束、卡座、吧台和四位随节拍律动的卡通人物。
彩色音垫与人物服装使用湖绿、橘黄和灰蓝；房间与音响采用深炭蓝衬托灯光。

1. 默认采用「完整编曲」，五个部分各四小节。在工具箱可选择「Drop 循环」或「完整编曲」。
   Drop 循环只录制主段；完整编曲可分别
   录制 Intro、Breakdown、Build-up、Drop、Outro，每个部分有独立的五轨与 1 / 2 / 4 小节。
   用「速度 -5」「速度 +5」调整 BPM；停止播放后可调整速度。
2. 选「底鼓」，触碰「录下这一圈」，数四拍后敲打击垫。满一圈自动回放。
3. 选「拍手」「贝斯」「旋律」或「和弦」，再点「录下这一圈」，下一圈开始录音，已有轨继续播放。
4. 已有轨再次录音会叠录；「撤销 / 恢复」切换本轨上一次乐段。各轨可单独静音、调音量。
5. 完整编曲的部分按钮位于音轨下方：薄荷色是当前部分，黄色表示已有录音。
   选部分会停止当前播放；「试听本段」循环当前部分，「播放全曲」按
   Intro → Breakdown → Build-up → Drop → Outro 播放一次。工具箱可撤销或清空当前部分的当前轨。
6. 保存保留全部部分、当前模式、速度、音量和对齐设置，切换模式会保留其他部分。
   旧工程按 Drop 循环载入。WAV 导出到设备 `Music/SpatialLoopV3`：
   Drop 模式导出四圈，完整编曲导出所有部分各一次，保留未录部分的小节时长。
7. 新建、清空、载入需在 3 秒内再次触碰同一按钮；停止、切部分、切模式和切后台会取消未完成录音。

手指靠近显示青色，触发显示琥珀色。推杆触碰即定位，保持接触横向滑动即可调节，
离开推杆所在行会释放。台高默认 1.10 m，可每次升降 10 cm。

交互只接收左右食指指尖，与 SpatialUI 控件实际触碰面直接检测接触。其他指尖也会在
接触分发层被过滤。原生指针事件被消耗，按钮和推杆的原生回调为空；
手掌、手腕、射线、捏合和单独手柄输入不能激活控件。
实际手感仍需佩戴设备验证。

V3.2 统一中文操作文案，中英文与数字使用内嵌 Loop Sans SC 常规 / 半粗字体；
音名、和弦、BPM 和 WAV 保留通用记号。按钮主副标签居中，推杆百分比靠右对齐，
播放 / 停止 / 录音采用矢量图形。字体采用 SIL OFL 1.1，来源与重建方式见
[tools/prepare_fonts.py](tools/prepare_fonts.py)，许可证随 APK 分发。

当前自动演奏为原创 Future Bounce「霓虹弹跳」，128 BPM。四拍预备后六次逐轨录音，
约 47 秒形成五轨循环，再演奏 40 小节 / 75 秒的 Drop、Breakdown、Build-up 与 Outro 变化。
谱子与 `music/neon_bounce/score.json` 一致，使用音频采样时钟调度，无需电脑脚本。
全程显示完整编曲页面；录音阶段选中 Drop，编排阶段的部分高亮和各轨音符数随实际乐段变化。
运行中再次点「停止演奏」恢复原工程，工具箱也可点「恢复原工程」。
自动演奏期间允许调整音量，手动音垫与编辑暂不触发。
切后台会停止自动演奏并恢复原工程；已保存的工程不被自动覆盖。
抬起超过面板 2 厘米即可重敲，无等待定时器；按钮反馈 45 ms，减少额外音频缓冲。

V3.6 加入封闭房间、吸音墙面、后墙波形、真实 PBR 灯光和四位街头服装人物。
人物有独立膝盖、手肘与头部动作，交替抬脚、侧步、弹跳和举手；脚部 IK 保持落地。
灯光、波形与动作跟随音频采样时钟，播放时按段落改变能量，停止时轻微律动。
台体改为灰蓝色，猫耳、腮红与粉色主题改为波形标志与中性色。

V3.7 按夜店方向重做：2.85 米完整顶棚、入口门与出口标志、卡座、桌子和吧台。
基底照明调低，两个聚光灯带半透明可见光束。四个人分别使用 Groove、Step-touch、
House 小步和肩部律动，共用音乐重拍，降低抬脚、弹跳和摆臂幅度；其中两位为女性角色。
主扩/低音音箱置于舞池两侧并向内偏转，桌面监听音箱置于演奏台背部支架上，朝向演奏者。
详细记录见 [docs/revision-3.7.md](docs/revision-3.7.md)。

V3.8 增加暖白顶灯与柔和补光，提高整体可见度；四个人各有一盏聚光灯，
覆盖头部、身体与脚部。台边音箱及所有支架/横梁移除，声音来自左右房间 PA 主音箱。
台两侧改为唱片摆件与小型波形灯，装饰放在音垫范围之外。
详细记录见 [docs/revision-3.8.md](docs/revision-3.8.md)。
