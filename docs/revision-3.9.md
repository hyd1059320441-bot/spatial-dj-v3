# 节拍俱乐部 V3.9

按用户反馈提高角落可见度：环境光由 -1 提至 +1 EV（强度为前版四倍），
基底补光由 130 提至 260 lux。墙面、地板、顶棚、卡座与门的材质改为更明亮的炭灰蓝，
保持夜店配色，同时避免角落物体使用接近黑色的表面。

四位人物统一使用白肤色 `#F9F6F0`，脸、耳朵、鼻子、手臂与手部使用同一肤色材质。
照射人物的聚光灯改为中性白光，减少肤色被蓝/绿色灯光染色；彩色灯口、灯条和光束保留。
四人独立聚光、四种舞步、房间 PA 音箱与台侧唱片/波形摆件继续保留。

本轮仅做照明/材质与肤色更新。前一轮 V3.8 自动回归在工具页读取自动状态时发生空指针，
该长回归未计为通过；本轮不会把旧自动报告当成本版通过证据。
不进行头显截图或指尖延迟验证。
