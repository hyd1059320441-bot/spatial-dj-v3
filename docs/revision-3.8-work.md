# V3.8 补光与台面清理

用户反馈：V3.7 太黑；聚光灯只照前排，后排照不到；底鼓/和弦附近出现监听音箱连杆。
要求添加其他光源、看得清聚光灯即可，移除台边音箱，使用房间音箱，台边放其他装饰。

保留深色夜店墙/地板，IBL 从 -3 提至 -1 EV；基底方向光从 32 提至 130 lux，
增加三块可见暖白顶棚灯板。最终每个人上方一盏聚光灯，共四盏，
14° 内锥 / 22° 外锥，落点小范围摆动；覆盖实际头部边界、身体和脚部。
双宽锥方案虽通过四人覆盖检查，但持续播放负载较大，最终换成四个窄光锥，
缩小灯光与透明光束覆盖面积，并保留环境与方向光作为柔和补光。

删除全部桌面监听音箱、立架、托板、横梁、连杆，声音绑定现有左右 PA 主音箱。
台两侧更换为唱片造型摆件和波形灯；支座在面板背后，装饰与按钮留出横向间距。
原两种录制模式、音乐和输入/台高规则保留。无需截图或指尖延迟验证。

验证：采样舞步运动范围计算四人光锥覆盖；实际 ECS 四人头/身体/脚部覆盖，
台边装饰不侵入 UI，PA 音频绑定和停止后释放，五轨及长自动演奏回归。
