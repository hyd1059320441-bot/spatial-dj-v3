# SpatialLoop V3.5

录制模式入口位于「工具箱」。

- **Drop 循环**：录制、叠加五轨主段，「播放 Drop」持续循环，WAV 导出四圈。
- **完整编曲**：Intro、Breakdown、Build-up、Drop、Outro 各有独立五轨及 1 / 2 / 4 小节。
  在音轨下方选部分，再点「录下这一圈」。薄荷色表示当前部分，黄色表示已有录音。
  「试听本段」循环当前部分；「播放全曲」从 Intro 开始，依次播放各部分一次，Outro 后停止。
  未录部分保留其时长。工具箱的撤销、清空仅作用于当前部分的当前轨。

部分和模式切换会停止播放、取消尚未提交的本圈录音；已完成的所有录音保留。
清空某部分后调整小节数会清除该部分的旧撤销记录，避免恢复超出新长度的音符。
保存记录所有部分、模式、当前部分、独立小节数及音量/静音设置。
旧 v1 工程按 Drop 循环载入，进入完整编曲时保留原 Drop，并初始化其他四部分。
完整编曲导出一遍全曲 WAV，使用同一音色、采样时钟和混音引擎。
自动演奏前的备份包含完整工程，每次新演奏都会重新备份当前工程。

自动演奏曲目仍为原创「霓虹弹跳」Future Bounce；段落名使用 Drop、Breakdown、
Build-up、Outro。手动录制各部分不依赖自动演奏脚本。

1000 × 700 面板继续使用内嵌中英文字体、粉彩配色和矢量播放/录制图标。
工具箱打开时隐藏音轨行，为模式选择与工具留出空间；演奏页保留两排音垫。
台面默认 1.20 米，仅左右食指输入。

指尖验证按用户要求暂停，临时时序采集已移除；当前不宣称真人延迟或真实 ECS
预测已验证通过。加强后的场景预测测试曾失败，明确标记为忽略；
见 [暂停记录](index-marker-verification-deferred.md)。

构建、测试数量及真机结果见 `artifacts/2026-10-28-v3.5/delivery.md` 和 `verification.json`。
