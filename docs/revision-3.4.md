# SpatialLoop V3.4

历史音乐实现记录。当前交付是 [V3.5](revision-3.5.md)；下文指尖注入测试结论已更正，
不可将旧产物中的宽松断言 PASS 当作实际预测有效的证据。

用户反馈：旧曲难听，换成 Future Bounce；实际食指领先指尖小球，优化跟手延迟。
默认台面 1.20 米、仅左右食指 IDs 1/6、中文内嵌字体及奶油粉彩风格继续使用。

## 音乐

自动演奏更换为原创「霓虹弹跳」，128 BPM，106 个录音音符，五轨录音计数
`[36,10,24,24,12]`。六次 pad() 录音保留实际录音及叠录行为，不预载完成工程。
录完后，同一音频采样时钟驱动十个变化段落，合计 40 小节、75 秒循环。
段落不会覆写录下的五轨工程；停止、取消及后台切换保留原工程恢复行为。

新增离线生成的 28 个 48 kHz 立体声音色，启动时加载，无音频回调文件 I/O 或合成。
旧音垫 ID 保持原义，贝斯尾部新增 F1/G1，底鼓尾部新增冲击/上升。旧 `.loop` 文件
版本与序列化格式继续兼容。48 个声部上限。

混音增加底鼓侧链、失谐立体声主音、滤波贝斯、和弦短奏、交叉反馈延迟及短混响；
固定缓冲、无前瞻软限幅。WAV 导出使用同一引擎和音色。完整编排试听放在
`music/neon_bounce`。主文件实测 -15.2 LUFS、true peak -1.4 dBFS。

## 指尖

旧路径由 Compose withFrameNanos 读取 latestData，并写入小球。新路径用 SDK 公开
DataProvider.addListener 在工作线程复制两根食指的位置与单调接收时间，经 volatile
mailbox 发布；绑定场景的公开 ECS System.update 在主线程读取最新样本并写入小球。
按场景 root ID 核验归属，关闭和暂停移除 listener；每次启动使用新 mailbox，避免旧
回调污染新生命周期。

小球位置使用纯显示预测：接收后额外 10 ms，总预测时间最多 18 ms、位移最多 12 mm；
异常跳变、快速反转、不连续采样不预测，25 ms 后停止外推，50 ms 后隐藏。
所有接触、滑块、按键捕获只使用实测位置，不使用预测点。

尚未获得传感器捕获时间的公开查询 API。接收至场景时间不能等同于相机曝光至显示
延迟。主观跟手感需用户在头显上确认，不能从自动注入测试宣称延迟归零。

## 验证

48 项 JVM 检查通过，包括采样时钟、录音、旧工程文件、声部压力、立体声音色解析、
十个段落、实际引擎母文件渲染，以及预测的过期、跳变、反转、丢失及乱序边界。

首轮真机三项 LiveLoopTest 通过：17 页中文及布局检查、五轨播放/保存/载入/WAV/
台体几何/后台释放，自动演奏的六次录音与十个段落。完整自动播放观察 200 次全部
有声，左右空间音频各新增 0 次 underrun，缓冲各 1536 帧。食指接触分发 p95 1.264 ms
只代表应用分发开销。

旧 ECS 注入测试曾显示 PASS，但位移断言不充分，z=.018999944 与原始 .019 的差异
只是浮点误差。加强为至少 2 mm 后测试失败，注入样本曾在 ECS 消费前老化至 106 ms，
超出 50 ms 的有效窗口。实际场景预测尚未验证通过，不能据旧报告声称该问题已解决。
用户随后明确暂停指尖验证，保留实现并移除临时采集；测试标记为忽略。
历史自动演奏新增 underrun 为 `[0,0]`。
普通运行另采集 120 次时序报告：预热后有效接收样本 79 次，场景更新间隔中位数
11 ms、p95 13 ms，回调接收至场景读取中位数 1.272 ms、p95 11.009 ms。
观察到单次 209 ms 场景间隔，不能宣称所有帧均无停顿。
这些值排除传感器曝光和最终显示延迟。最终结果及产物放在
`artifacts/2026-10-28-v3.4`，时序与暂停记录在
[index-marker-verification-deferred.md](index-marker-verification-deferred.md)。
