# V3.6 room implementation

用户要求：演奏台放在房间里，有灯光、人物跳舞，和音垫风格统一；音垫减少女生化元素。
直接实现、构建、安装；保持已有两种录制模式和默认 1.20 米台高，指尖验证仍暂停。

设计方向：米白、炭蓝、湖绿、橘黄、灰蓝的圆角街机俱乐部。保留音垫大尺寸与清晰文字，
减少粉色与猫耳/腮红造型，标题图形改为节拍波形。共享颜色常量用于 UI 与原生材质。

原生几何构建封闭房间、舞池、吸音墙面、灯具与后墙波形装饰。
房间边界约 x=±3.4，z=-5.4..1.8，顶高 3.8 米；演奏台保持前方 z=-.63。
四位穿街头服装的卡通人物位于舞池 z=-2.8..-3.8，留出演奏台操作空间。
采用分段四肢、头发/帽子、面部与鞋子，动作包括弹跳、侧步、交替抬脚和举手。
脚部使用双骨 IK 保持支撑脚落地，不能用整个静态人偶平移冒充跳舞。

房间/人物用 PhysicallyBasedMaterial 实际受光；UI 与设备装饰使用无光照颜色保证可读性。
方向光提供无阴影基底（避免封闭天花板遮断方向光），两个舞池聚光灯提供氛围。
设备回归曾出现 GPU_NO_RETIRE 并重启 Runtime；最终去掉动态阴影图和大范围点光，
房间/人物采用共享的 44 面倒角方体与 168 面平滑球体，显式背面剔除、深度和无自发光，
降低负载并保留 PBR 实际受光与灯光颜色、方向、强度变化。最终性能需重新采集。
灯光强度、摆动与人物能量随播放节拍及段落变化，闲置时有轻微舞动。
动画在绑定场景的 ECS 主线程更新；后台暂停、关闭释放，复用网格与材质。
AndroidManifest 的 pico.spatial.stage.style 由 Mixed=1 改为 Full=3，以进入完整虚拟房间。

验证：纯算法覆盖 IK 长度/支撑脚/动作周期；设备检查房间、四位人物与真实灯光组件，
四肢在实际 ECS 中运动，墙体不遮挡音垫、布局/中文不溢出、播放与后台回收正确。
无需头显截图。最终包与证据放在 artifacts/2026-10-28-v3.6。
