# 节拍俱乐部 V3.7

舞蹈改成四种小幅夜店律动，四人共用音乐节拍，没有人物之间的时间偏移：

- Groove：重拍屈膝、左右重心摇摆，手部保持腰胸附近。
- Step-touch：左右侧步并拢，拍前移动、重拍落脚。
- House 小步：前后换步与小幅摆臂，抬脚最高约 3.2 厘米。
- 肩部律动：肩膀交替扭动、轻点脚，身体随鼓点下沉。

所有人物取消大幅举手，肩膀展开角度低于 30 度，身体摆动与脚步依然使用双骨 IK。
两位女性角色分别为马尾和长发，另外两位男性穿休闲外套，四人采用浅肤色。
各人服装、发型、朝向与舞步不同。

房间改成深炭蓝夜店：完整顶棚降低到 2.85 米，配横梁、顶棚内嵌灯条、入口门、
门把手、窗及出口图形标志。两侧设置卡座和圆桌，前侧加入吧台和背光置物架。
地板和墙面调暗，基底灯从 650 lux 降至 32 lux，并使用低强度的独立环境光；
两个舞池聚光灯带淡淡的可见光束，灯光强度与落点随节拍变化。
光束使用半透明效果，不遮挡人物，落点保持在舞池地面。

音响重布置：舞池两侧为主扩加低音的落地堆栈，向中心偏转并稍微向下倾斜。
演奏台两侧改为小型监听音箱，通过后部横梁/支架支撑，朝向演奏者，随台面升降。
不再使用两根突兀的高脚音箱支架。

SDK 不接受最初的通用 RGBA16F 环境贴图；最终使用 SDK 内置且支持的 RGB11F
环境贴图（含 SH 和预过滤 mip），环境强度设为 -3 EV。
音垫布局、两种录制模式、原创自动演奏及 1.20 米默认台高保持。
不运行指尖延迟验证或头显截图验证。

69 项 JVM 测试通过，包括四舞步区别、共同重拍、手臂幅度和脚部 IK。
三项真机回归通过，覆盖房间与光束、音箱支撑/朝向、五轨播放、自动演奏及生命周期。
两路音频新增欠载均为 0，当前回归未新增 GPU_NO_RETIRE。

本轮 30 秒五轨播放的 Runtime 采样平均 85.55 FPS，范围 76–92；约 128 秒
自动演奏平均 75.95 FPS，范围 59–90，长自动演奏存在帧率波动。
同一场景的 18 秒灯光对比中，保留环境光及光束平均 90 FPS，关闭光束 89.72，
关闭环境光 87、两者关闭 83.33；没有稳定证据表明移除灯光能改善长段落帧率。
最终保留夜店光照效果，不宣称已稳定 90 FPS，也不将算法/组件检查当成主观美术认可。
临时性能切换代码只存在于测试期间，最终测试源码已移除；原始采样保留。

测试与最终包见 `artifacts/2026-10-28-v3.7`。
