# 节拍俱乐部 V3.8

提高房间可见度：保留深色夜店墙面与地板，环境光由 -3 提至 -1 EV，
暖白基底灯由 32 提至 130 lux，增加三块暖白顶棚灯板。
彩色聚光灯与可见光束继续保留。

四个聚光灯分别位于四个人上方，前后排都有独立照明。
内/外锥角度为 14° / 22°，灯光落点只在小范围内摆动。
验证覆盖头部边界、身体与脚部，在不同舞步和能量下保持覆盖；
不再仅以光束打到舞池地面作为人物受光的判断依据。

删除台两侧监听音箱以及所有托板、横梁和连杆，声音绑定房间现有的左右 PA 主音箱。
台边更换为唱片造型摆件和小型波形灯；支座处于面板后方，
完整装饰边界距音垫区域至少 2.5 厘米，避免穿过底鼓、和弦等控件。
两种录制模式、原创自动演奏、四种舞步及 1.20 米台高继续保留。

检查基于实际 ECS 灯光和几何覆盖、PA 绑定、播放与回收，不包含头显截图或指尖延迟验证。
