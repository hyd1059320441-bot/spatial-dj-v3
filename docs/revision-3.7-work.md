# V3.7 夜店改造

用户反馈：原舞蹈像大幅度民族舞，四人的变化不足且不踩拍；需要女性角色与浅肤色人物。
房间太亮、顶棚不明显、没有门，音箱位置/高度/朝向/样式突兀。直接修改并安装。

动作改成四种小幅俱乐部律动：重心 Groove、Step-touch、House 小步、肩部律动。
四人共用绝对音乐节拍，不使用人物时间偏移；身体下沉和落脚对齐整数拍。
手臂保持腰胸附近，取消全场举手，降低抬脚和上下弹跳幅度。两位女性、两位男性。

完整深色顶棚降低到 2.85 米，增加顶棚拼板/横梁、入口门及出口标志、卡座和桌子。
深炭蓝墙、暗地板；降低基底照明并提供独立的暗色环境光贴图，突出舞池聚光和可见光束。
两侧 PA 改成有底座的主扩/低音堆栈，朝向舞池；演奏台两侧使用朝向演奏者的桌面监听音箱。
音垫配色与排版、两种录制模式、自动曲目和默认台高保留。

验证：四种舞蹈区别、重拍/落脚时点、低幅动作、IK 长度与不穿地；
真机场景顶棚覆盖、入口、女性角色、光照/光束/深色环境、音箱摆位与播放稳定性；
采集 Runtime 性能，保留生命周期回归。指尖与截图验证继续暂停。
