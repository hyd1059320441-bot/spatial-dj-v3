# 节拍俱乐部 V3.6

演奏台现在放在完整虚拟房间中：地板、四面墙、天花板、吸音板、舞池、长凳、
灯具、后墙波形和后置音箱构成统一的街机俱乐部。进入应用即展示房间。
演奏台默认仍为 1.20 米，前方保留操作空间。

音垫、台体、音箱与房间使用统一的米白、炭蓝、湖绿、橘黄和灰蓝。
减少粉色主题，移除猫耳、腮红和猫脸，图标与标题改为波形及「节拍俱乐部」。
按钮尺寸、音轨顺序、两排音垫、中文字体和矢量播放/录制图标保留。

四位人物穿不同颜色的街头服装，带头发或帽子、面部、鞋子和独立四肢。
动作包含侧步、交替抬脚、弹跳、摆臂和举手；膝盖、手肘与头部独立运动。
双骨 IK 保持腿长与脚底高度。音乐播放时，灯光、人物和后墙波形跟随同一
音频采样时钟；Intro / Breakdown / Build-up / Drop / Outro 有不同动作能量。
停止播放后保持轻微律动。切后台暂停，退出释放资源，再次进入重新创建。

灯光使用一个方向光和两个舞池聚光灯，房间及人物使用真实受光的 PBR 材质。
文字、音垫和装饰灯条保持无光照材质以保证可读性。最终关闭动态阴影；
保留实际灯光颜色、方向与强度变化。

早期高负载版本两次遭遇设备 `GPU_NO_RETIRE`：系统终止 Spatial Runtime，
随后应用因 Runtime 断连退出。去掉阴影后仍有约 64 FPS 的负载问题。
最终减少大范围灯光覆盖、改用共享的 44 面倒角方体与 168 面球体，并明确
设置背面剔除、深度和无自发光。优化版本五轨播放 30 秒的 30 个 Runtime
采样均为 90 FPS，GPU 时间中位数约 10.63 ms。中断证据随交付保存，
这些负载调整不构成对 GPU 驱动根因的认定。

约 128 秒自动演奏回归的 127 个 Runtime 采样平均 88.31 FPS，范围 72–91，
GPU 时间中位数 12.6 ms；逐轨录音和段落切换期间仍有短时帧率下降。
两路音频新增欠载均为 0，五项真机回归和最终文字配色补查通过。
优化后验证期间未新增 GPU_NO_RETIRE。

Drop 循环、完整编曲、原创「霓虹弹跳」自动演奏与工程存储继续可用。
指尖验证仍按用户要求暂停，没有运行预测或真人延迟验证，也没有截图验证。
最终测试结果和 APK 见 `artifacts/2026-10-28-v3.6`。
